Release notes

1.1.0 — Website services and admin

June 2026

  • Moved advertisement management and aggregate usage statistics from the extension to the website admin dashboard.
  • Added a PHP/MySQL service for ad content, anonymous aggregate ad events, and credit usage counters.
  • Added website administrator first-time setup, sign-in, ad editing, dashboard totals, and password changes.
  • Added searchable FAQ, a theme toggle, this release notes page, and a privacy notice.
  • Added an extension setting for an optional website API endpoint. Media files and media URLs are not sent to it.

1.0.0 — Browser media detection

  • Detect media from page elements and observed network activity, with rescan and current-playback prioritization.
  • Show available format and size information, and manage supported downloads in local history.
  • Disable direct YouTube downloads when the detected resource may be an incomplete stream.
