GOOD TO KNOW

Clear about what’s supported.

Media websites work in different ways. Here’s what to expect.

Can it save every video it finds?

No. Detection means a media source was found, not that it can be saved as one complete file. Direct progressive files are supported; some sources require special headers or player-specific access.

What about HLS and DASH streams?

The extension can identify these streams and show available variants, but it does not combine stream segments into a video file. It can save a playlist for use with a compatible media tool.

Can I download YouTube videos here?

No. YouTube detections do not offer direct download because requests may be separate audio/video tracks or partial data. Use YouTube’s built-in download option where available.

Does the extension upload my media?

No. Detection and download management run in your browser, and media files are not uploaded. If an administrator configures the optional website API, the extension sends anonymous aggregate ad events (impressions, completions, clicks, and credits used) for the website dashboard. See the privacy notice.

Only save media you have the right to download. Follow the source website’s terms and applicable law.
