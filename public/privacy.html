YOUR DATA, EXPLAINED

Privacy notice

Last updated: June 2026

Video Downloader is a browser extension for finding and managing media sources. Media detection and download history are handled in your browser. The extension does not upload the video or audio files it finds or downloads.

Optional website connection: if a site administrator configures the Ad API URL in extension Settings, the extension contacts that API to retrieve active ad content and send aggregate ad and credit counters. If no API URL is configured, those website services are not available.

Information stored on your device

  • Extension preferences, detected media metadata, download history, and ad unlock/credit state are stored in browser extension storage.
  • Detected media metadata can include page and media URLs, titles, formats, and size information. It is not sent to the website API.

Optional aggregate events

When the website API is configured, the extension can send counts for ad impressions, completed ad views, ad clicks, and credits used. These event requests do not include media URLs, page URLs, download filenames, or an extension account identifier. The API stores aggregate counters for the administrator dashboard.

The website operator’s hosting provider may record ordinary server access or error logs, which can include network information such as an IP address and request time. The operator controls the server, database, log retention, and any privacy obligations for that deployment.

Website administrator information

The optional website admin service stores an administrator email address, a password hash (not the password), advertisement content and aggregate event totals. Admin login uses a server-side session cookie. The MySQL server and its backups are controlled by the website operator.

Third-party websites

Browsing and downloading media involves requests to the source website and its content delivery providers. Their own privacy policies and terms apply. Video Downloader does not control those services.

Choices and contact

You can leave the Ad API URL blank or remove it in extension Settings to stop optional website API requests. You can clear the extension’s local download history in Settings. Contact the operator of the website hosting this copy for questions about its server-side data.
